# Dictionary downloads with the same name

The download catalogue may list several dictionaries with the same display name and different sources. Each source stays selectable. For entries sharing a display name, a URL-derived suffix distinguishes their installation directories and StarDict booknames, so each can be enabled, disabled, selected in presets, and looked up independently. While the display name and same-name catalogue membership stay unchanged, downloading the same entry again prepares the replacement in a staging directory and only replaces the existing version after extraction, metadata discovery and identity updates succeed. Failed preparation keeps the previous dictionary and its disabled and ordering settings. If publishing the replacement fails, the old directory is restored; if the filesystem also refuses restoration, the error reports the retained recovery directory instead of deleting it.

Staging and recovery directories use the reserved `.koreader-dict-download-` prefix next to the installation. They are excluded from dictionary discovery and lookup, even if cleanup fails. Recovery files are kept for manual recovery when both replacement and restoration fail. Reinstallation needs room for the downloaded archive and a newly extracted replacement while the installed copy is retained; peak storage includes both extracted versions and the archive. If cleanup fails, staging files also continue to occupy space. After checking which version to keep, users may remove leftover staging directories manually; preserve any `previous` directory until recovery is complete.

Older installations may lack a download URL identity. When a download targets a different installation path, existing directories and their path-based disabled and ordering settings are left in place; same-name catalogue conflicts add a URL-derived suffix and can therefore leave older name-only copies installed. Unique-name entries still use name-only paths and can replace any existing installation at that path, including an unidentified legacy or manually installed dictionary. KOReader cannot infer which source created it. If re-downloading leaves duplicate copies, inspect them before manually removing one.

The installation path also depends on the catalogue display name and whether that name has conflicting sources. If a later catalogue changes either, downloading the URL again may create another installation or select an existing name-only path for replacement. Disabled and ordering settings remain keyed by their original paths. Check the copies before manually removing one or setting preferences for the new path. There is no migration across such catalogue changes.
